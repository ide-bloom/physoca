# Limitations

- Physoca is decision-support software for review by a health care professional; it does not diagnose, prescribe, or provide taper schedules.
- It does not perform e-prescribing, EMR integration, document parsing, or general drug-drug interaction checking beyond its published rule packs.
- Missing clinical data (such as diagnoses or start dates) prevents full evaluation of rules that depend on those fields; Physoca reports these as `needs_data` rather than guessing.
